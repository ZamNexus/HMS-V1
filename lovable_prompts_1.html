Citi Clinic HMS — Prototype Build Prompts

Nine sequential prompts for building a production-grade Hospital Management System prototype in Lovable. Start with Prompt 01 in a new project, then paste each subsequent prompt in order — each builds on the previous.

How to use
Create a new project at lovable.dev. Paste Prompt 01 and wait for full generation. Then paste each prompt one at a time in order. Never skip. If something generates incorrectly, correct it before moving to the next prompt.
